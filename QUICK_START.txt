📦 INSTALLATION STEPS
═══════════════════════════════════════════════════════════

1️⃣  Extract the ZIP file
   └─ Unzip to your desired location

2️⃣  Open Terminal/Command Prompt
   └─ Navigate to the project folder
      cd luxury_car_showroom

3️⃣  Create Virtual Environment

   Windows:
   ────────
   python -m venv venv
   venv\Scripts\activate

   Mac/Linux:
   ──────────
   python3 -m venv venv
   source venv/bin/activate

4️⃣  Install Dependencies
   └─ pip install -r requirements.txt

5️⃣  Run the Server
   └─ python manage.py runserver

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════

❌ "Module not found"
   → Activate virtual environment
   → pip install -r requirements.txt

❌ "Port already in use"
   → python manage.py runserver 8080

❌ "Images not showing"
   → Check media folder exists
   → Upload images via admin panel

❌ "Admin login failed"
